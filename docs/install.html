Install AuraSolve in 5 steps

About a minute in Google Chrome. If the download didn't start, click here to download it again.

  1. 1

    Find the zip you downloaded

    It's called AuraSolve-extension.zip.

    • Open Finder and click Downloads in the sidebar.
    • Or click the download arrow in the top right of Chrome and choose Show in Finder.
    • Open File Explorer and click Downloads.
    • Or click the download arrow in the top right of Chrome and choose Show in folder.
  2. 2

    Unzip it

    • Double-click AuraSolve-extension.zip.
    • A folder named AuraSolve-extension appears next to it.
    • Right-click AuraSolve-extension.zip and choose Extract All…
    • Click Extract. A folder named AuraSolve-extension opens.
    • Don't skip this. Chrome can't load the extension from inside the zip.

    Tip: move the AuraSolve-extension folder to Documents now. Chrome runs it from wherever it sits, so if you delete it later, AuraSolve stops working.

  3. 3

    Open Chrome's extensions page

    • Copy this into Chrome's address bar and press Enter:
    • Or click the ⋮ menu → Extensions → Manage Extensions.
  4. 4

    Turn on Developer mode and load the folder

    • Flip the Developer mode switch in the top right corner on.
    • Click Load unpacked in the top left.
    • Pick the AuraSolve-extension folder and click OpenSelect Folder.

    Pick the folder that has manifest.json directly inside it. If Chrome says "Manifest file is missing," you picked the wrong folder. On Windows, Extract All sometimes makes a folder inside a folder. Open it once and pick the inner one.

  5. 5

    Pin it and open MyLab practice

    • Click the puzzle piece icon in Chrome's toolbar and pin AuraSolve.
    • Open a MyLab practice question, or refresh it if it was already open.
    • Press Fill answers in the AuraSolve panel beside the question.

Something not working?

Chrome says "Manifest file is missing or unreadable"

You picked the wrong folder, or you picked the zip itself. Unzip first, then in Load unpacked choose the AuraSolve-extension folder that has manifest.json directly inside it.

I don't see the AuraSolve panel on MyLab

Refresh the MyLab tab after installing. Make sure AuraSolve is switched on in chrome://extensions, and that you're on a practice question, not the assignment list.

How do I update to a new version?

Download the new zip and unzip it. In chrome://extensions, click Remove on the old AuraSolve, then use Load unpacked again with the new folder. Delete the old folder after that.

Chrome shows a "Developer mode extensions" warning

That's normal for extensions loaded with Load unpacked. Click the X to close it. AuraSolve keeps working.

AuraSolve disappeared after I deleted the folder

Chrome runs the extension from that folder, so deleting it removes AuraSolve. Download it again, put the unzipped folder in Documents, and repeat step 4.
