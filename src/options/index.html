Connect your own OpenAI API key to start learning.

Stored in this Chrome profile, accessible only to extension pages and its service worker. It is not encrypted or synced. Never share a folder containing your real .env file.

Use a model available to your API account that supports the Responses API and structured outputs.

Three ways to learn.

✈️ AutoPilot fills and submits up to five ungraded practice questions, then explains each answer. It stops if correctness cannot be verified.

✍️ Fill a field gives you an answer preview and fills the selected field after you review it. You submit.

💡 Explain gives you a tutor-style paragraph without changing the page.

Your detected question and answer-field labels go directly to OpenAI when you choose a mode. No AuraSolve account, subscriptions, analytics, or hosted backend. OpenAI API charges still apply.

To test: run npm run demo from the extension folder and open the practice lab. On other websites, click the AuraSolve toolbar icon. Unsupported pages need a dedicated adapter.
