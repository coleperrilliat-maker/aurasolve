Three ways to learn.

✈️ AutoPilot fills and submits up to five ungraded practice questions, then explains each answer. It stops if correctness cannot be verified.

✍️ Fill a field gives you an answer preview and fills the selected field after you review it. You submit.

💡 Explain gives you a tutor-style paragraph without changing the page.

Your detected question and answer-field labels are sent to AuraSolve Cloud on Railway, which calls OpenAI securely. Your OpenAI key stays on the server — not in Chrome.

To test locally: run npm start for the API and npm run demo for the practice lab. After deploying to Railway, update src/shared/config.js with your public URL and client key, then reload the extension.
